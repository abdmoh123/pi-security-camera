# Pi Security Camera

A project about a remote Raspberry Pi security camera system.

## Contents

- [Flutter client](/client/README.md)
- [Server](/server/README.md)
- [Camera client](/camera/README.md)

## Summary

The main purpose of this project is to reduce the amount of data that needs to be sent to the server.
This is mainly useful for situations where mobile data is metered and limited.

Additionally, this project is entirely self-hosted.

Unfortunately, the videos being recorded and uploaded are not end-to-end encrypted, which means that you must trust the owner of the server.
